# Reply templates

> **EXAMPLE TEMPLATE.** This is a model to start an interview from, not anyone's real playbook. Everything in [brackets] gets replaced with the user's own answers. Never run it as-is.

## Yes, with a next step
Hi [name],

Yes, [answer]. [Next step and when].

[Sign-off]

## Not yet, here's when
Hi [name],

I can't [do X] yet. I'll have [it / an answer] by [day].

[Sign-off]

## Passing it on
Hi [name],

[Person] handles [topic], so I've copied them in. [Person], could you [ask]?

[Sign-off]
